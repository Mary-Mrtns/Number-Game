# 🎯 Number Game

Um jogo de adivinhação de números feito com **HTML, CSS e JavaScript puro**, desenvolvido durante o curso de JavaScript da **Alura**.

O computador sorteia um número secreto e você tenta descobrir qual é, recebendo dicas a cada palpite.


---

## 🎮 Como jogar

1. Abra o jogo no navegador.
2. Digite um número no campo de entrada.
3. Clique em **Chutar**.
4. Leia a dica: o número secreto é **maior** ou **menor** que o seu palpite?
5. Continue tentando até acertar.
6. Ao acertar, veja quantas tentativas você precisou e clique em **Novo jogo** para jogar de novo.

---

## ✨ Funcionalidades

- Sorteio de um número secreto aleatório a cada partida
- Dicas de "maior" ou "menor" a cada palpite
- Contagem de tentativas
- Botão para reiniciar e começar um novo jogo
- Interface estilizada com CSS
- Leitura de texto
